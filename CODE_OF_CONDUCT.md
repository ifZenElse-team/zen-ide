# Code of Conduct

Zen IDE adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project, in every project space:
the repository, issues, pull requests and any community channels.

In short: be respectful and constructive, assume good intent, welcome newcomers, and focus on what
is best for the project and its users. Harassment, insults and personal attacks are not tolerated.

## Enforcement

Report unacceptable behaviour to the maintainers at **support@ifzenelse.space**. All reports are
reviewed promptly and kept confidential. Maintainers follow the enforcement guidelines of the
Contributor Covenant 2.1.
