Zen IDE

Fast, native, open-source IDEs, written in pure Rust and built for working with AI agents.

Early development: GoGarden, RustRonin, WebWave, JvmJizo, SqlScroll and DevopsDaruma are in preview

Zen Toolbox

The entry point to the family: a small tray app that will install, update and launch every Zen IDE as each one is released.

Install from Terminal

curl -fsSL https://ide.ifzenelse.space/install.sh | sh

Installs the latest Zen Toolbox into Applications and opens it, without the “could not verify” warning.

Checking for the latest release…

The app is not notarised yet, so macOS blocks the first launch of the downloaded app: right-click Zen Toolbox in Applications and choose Open. After that it opens normally.

Install from Terminal

curl -fsSL https://ide.ifzenelse.space/install.sh | sh

The same script as on the Mac: installs the latest Zen Toolbox for your user, without sudo, adds it to the applications menu and starts it. Ubuntu 22.04 and later, x64 · preview.

Zen Toolbox for Linux GoGarden for Linux

Linux builds come out from time to time, not with every release, so the Linux version may be behind the Mac one. Or install a package for every user: sudo apt install ./zen-toolbox_<version>_amd64.deb (or the GoGarden one); a new version is installed the same way.

GoGarden for Windows Zen Toolbox for Windows

Windows builds come out from time to time, not with every release. Unzip the archive anywhere and run bin\gogarden.exe (or bin\toolbox.exe). They are not signed yet, so SmartScreen may warn on the first run: choose More info, then Run anyway.

Built for AI agents

Zen IDE is made for a developer and an AI agent working on the same project at once. The agent works the IDE the way you do, not through a chat box bolted onto the side.

  • Every action is a commandOpening a file, navigating, renaming, running: everything you can do with the mouse or a shortcut is a command an agent can run too.
  • A built-in MCP serverTurn it on in Settings → Tools → MCP Server and connect Claude Code, Codex, Cursor or any MCP client to the running IDE. It listens on this computer only. How to connect.
  • The IDE's knowledge, sharedAgents read the same problems, symbols, usages and documentation that you see, straight from the language server.
  • You stay in chargeAn agent's edits land in your open editor, with undo, as if you typed them. Nothing leaves your machine unless you connect it.

Meet Kozō

Kozō (小僧), a young novice monk, is the mascot of the family. He meditates on the splash and welcome screens of every Zen IDE, in a robe of the IDE's colours and with something of its own.

  • RustRoninKeeps a wooden sword at hand; a glint runs along the blade.

The family

One shared engine, the Zen Platform, and one IDE per language. GoGarden came first; RustRonin, for Rust, WebWave, for the web, JvmJizo, for Java and the JVM, SqlScroll, for SQL and databases, and DevopsDaruma, for DevOps, join it. All six are in early development.
