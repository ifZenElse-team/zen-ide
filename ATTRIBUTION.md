# Attribution

Third-party material bundled with Zen IDE, and assets made by the project. Code dependencies are
listed in `Cargo.lock` and checked by `cargo deny` (deny.toml); their licence texts are in the
`THIRD-PARTY-NOTICES` of every release artefact, generated by `cargo xtask notices`
([docs/licences.md](docs/licences.md)). This file covers files and data.
