# Markdown plug-in changelog

Every release of the Markdown plug-in (`plugins/markdown`), newest first; the format is in
[../README.md](../README.md).

## 0.3.0 - 2026-10-24

### Added

- The headings in the **Structure** tool window, nested by level (`#` headings and underlined
  ones), each with its section; fenced code is never taken for a heading.
- Folding of each heading's section and of fenced code blocks.

## 0.2.0 - 2026-10-16

### Changed

- Heading marks (`#`) are coloured apart from the heading text.

## 0.1.0 - 2026-10-16

### Added

- The first release: highlighting for Markdown files (`.md`, `.markdown`): headings, emphasis,
  links, lists, quotes and code.
