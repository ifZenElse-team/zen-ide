# Node.js plug-in changelog

Every release of the Node.js plug-in (`plugins/nodejs`), newest first; the format is in
[../README.md](../README.md).

## 0.1.0 - 2026-11-06

### Added

- The first release, for projects with a `package.json`; WebWave comes with it, and every other IDE
  offers it in a notification when such a project opens. It is also in the Marketplace.
- **Node.js** run configurations: run a JavaScript or TypeScript file with ⌃⇧R, with Node options and
  the interpreter of your choice.
- Debugging of Node.js files and Jest and Vitest tests: breakpoints with conditions and log points, stepping,
  variables, evaluation and exceptions, with no download.
- **Node.js Tests** run configurations for Jest and Vitest: run icons next to `describe`, `it` and
  `test`, the test results tree as tests finish, and Rerun Failed.
