# Biome plug-in changelog

Every release of the Biome plug-in (`plugins/biome`), newest first; the format is in
[../README.md](../README.md).

## 0.1.0 - 2026-10-24

### Added

- The first release, from the Marketplace in every IDE and offered when a project has `biome.json`.
  The project's own Biome checks JavaScript, TypeScript, JSX, TSX, JSON, CSS and GraphQL files as you
  type, beside their own language server, offers its quick fixes with ⌥Enter and its safe fixes with
  Fix Problems or on save, and formats them with Reformat Code.
