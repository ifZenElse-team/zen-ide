# Prettier plug-in changelog

Every release of the Prettier plug-in (`plugins/prettier`), newest first; the format is in
[../README.md](../README.md).

## 0.1.0 - 2026-10-24

### Added

- The first release, from the Marketplace in every IDE and offered when a project has a Prettier
  configuration or depends on `prettier`. Reformat Code formats JavaScript, TypeScript, JSX, TSX,
  JSON, CSS, SCSS, Less, HTML, Vue, Svelte, Markdown, YAML and GraphQL files with the project's own
  Prettier, which respects `.prettierignore`; Settings → Languages & Frameworks → Code Quality Tools
  says whether it runs on Reformat Code and on save.
