# GitLab CI plug-in changelog

Every release of the GitLab CI plug-in (`plugins/gitlab-ci`), newest first; the format is in
[../README.md](../README.md).

## 0.2.0 - 2026-11-13

Needs Zen IDE 26.11 or later.

### Added

- The schema of GitLab CI/CD configuration, shipped in the plug-in: the YAML language server
  completes and checks `.gitlab-ci.yml` offline.

## 0.1.0 - 2026-10-16

### Added

- The first release: highlighting for `.gitlab-ci.yml`: keywords, job names, CI/CD variables,
  `rules` expressions, anchors, `!reference` tags, strings and comments.
