# React plug-in changelog

Every release of the React plug-in (`plugins/react`), newest first; the format is in
[../README.md](../README.md).

## 0.1.0 - 2026-10-23

### Added

- The first release, for React projects; no IDE comes with it, every IDE offers it in a
  notification when a project with `react` in its `package.json` opens, and it is in the
  Marketplace. `.jsx` and `.tsx` files are served by the JavaScript and TypeScript plug-ins and
  the TypeScript Language Server.
- In a Vite project (`vite.config.*`, or `vite` in `package.json`), the run configurations `vite`,
  `vite build` and `vite preview`, added once and run with the project's package manager.
- The file templates **React Component** (`.tsx`), **React Component (JSX)**, **React Hook** and
  **React Context** in **New**.
