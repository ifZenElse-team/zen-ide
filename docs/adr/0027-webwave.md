# ADR-0027: The web IDE is WebWave

- **Status:** Accepted
- **Date:** 2026-10-16
- **Amends:** [ADR-0019](0019-alliterative-product-names.md) (the name of the TypeScript and JavaScript IDE)

## Context

The IDE for TypeScript and JavaScript was named TsTorii. The owner found that "Ts" does not make
obvious that it is the IDE for web development, and asked for a name that starts with "Web".

## Decision

1. The web IDE is **WebWave**: id `webwave`, bundle identifier `space.ifzenelse.webwave`, launcher
   `wave`. The image is *The Great Wave off Kanagawa* by Hokusai; W-W keeps the alliteration rule.
2. For web development the first part of the name is **Web** instead of a language name, because the
   product covers TypeScript, JavaScript, HTML and CSS together. Every other IDE keeps the language
   name.

## Alternatives considered

- WebWisteria (long), WebWillow (less recognisable).
